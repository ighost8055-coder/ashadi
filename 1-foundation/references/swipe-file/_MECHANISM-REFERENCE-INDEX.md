# ⭐ THE MECHANISM REFERENCE INDEX — the 38 award references, mapped to M1–M16

> **What this is.** The human supplied 38 award-level reference images on **2026-10-03**, saved in `images/`, with the instruction: *"brand colours and font style remain the same, but everything else is revamped — like handing it over to a new agency; make sure camera, composition, visual treatment, everything is changed."*
>
> **`_image-gen-rules.md` was rebuilt from these images.** This file is the bridge back: **every mechanism in §B points to the actual picture that taught it.**
>
> ## ⛔ HOW THE REFERENCE RECREATOR MUST USE THIS
>
> **Written rules decay into generic advice; a picture does not.** *"M14 is a headline with a drawn underline and the subject in the gap"* is a correct sentence that can still produce something mediocre — because what makes the nib ad land is the **proportion** of the underline, the **weight** of the type against the ceiling, the **exact slackness** of the falling man's legs. None of that survives translation into prose.
>
> **So: before writing any prompt, OPEN the reference image for the mechanism you have declared.** Read the file with the Read tool — they are PNGs and they render. Judge your frame against the picture, not against my description of it.
>
> **And after rendering:** the rules govern *what gets prompted*, never *what the model returns*. **Compare the render to the reference by eye.** That comparison is the only real quality gate.

## ⛔ WHAT IS NOT AVAILABLE FROM THESE REFERENCES

Several are great **because of things this project bans.** Named here rather than smuggled in:

- **Type:** **16** (serif) and **35** (rounded display) — §E rule 2 permits **Inter only.** Their compositions transfer; their type does not.
- **Register:** **4** (competitor's pizza) and **3** (unflattering sunburn) run on a mildly uncomfortable tone. **Core Rule 14 requires the happy, vibrant gifting mood.** Take **3**'s reflection device; leave its register.
- **Likeness:** no reference here licenses depicting a real identifiable person. **Hard Rule 26 is absolute.**
- **Wordplay:** any double meaning in a reference headline is **unavailable** (Core Rule 15). **M1's hinge word and M14's gap are not exceptions** — a hinge word has one meaning, a gap is one literal missing word.
