# Brand Assets — attached reference images + shared idea source

> Real Kapruka assets that must be **attached to the image-generation tool and composited/matched, never redrawn from text** (human rule, 2026-07-18). Same discipline as the Kapruka logo. This keeps packaging, livery and identity pixel-consistent across every generated concept — **and** these assets are a **first-class source of ideas** for the whole system (see "Shared idea source" below).

## The attach rule (every image-gen prompt this system produces)
For any element that has a real asset below, **attach the file** and instruct: *"Use the attached [asset] exactly as provided — composite/match it; do not redraw, recolour or reconstruct it from text."* A generic stand-in (plain box, plain bag, plain van) = no brand and is banned; the real attached asset is the only acceptable version.

## Shared idea source (paid ads · Kelly organic · image prompts · brain-led ideas)
Per human rule (2026-07-18), these assets are not only for image generation — they are a **standing idea source across the whole system**, a `brand-asset` entry point alongside brain / research / competitor / broad-brand:
- **Image prompts (Reference Recreator):** depict + attach the real bag/box/van.
- **Paid ad ideas (Ideator / Art Director format-in-words):** the iconic purple bag with gold ribbon, the smile swoosh, the branded van arriving — ownable visual hooks a designer can build.
- **Kelly (organic content):** unboxing the purple gift bag, the "With love, from us to you." card, the van pulling up — native content beats.
- **Brain-led seeds:** the assets themselves suggest angles (the smile, "A world of choices," the arrival-on-the-doorstep moment).
