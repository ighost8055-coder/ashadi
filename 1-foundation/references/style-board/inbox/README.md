# Style-Board inbox — drop new style images here

Drop new reference images into this folder, then tell me **"ingest the style-board."**

For each new image I will:
1. **Scan it** (read the actual pixels).
2. **Add an `SB-###` entry** to `../_style-board.md` (title · image path · "style to emulate" notes · bucket), continuing the numbering (**next up: SB-049**).
3. **Extract its format** — if it's a *new* format/device not already in `../format-library.md`, add it there (with "best for" + the SB ref). If it matches an existing format, just note the extra SB ref.
4. **Refresh the taste** — update `../taste-digest.md` only if the new images shift or add a taste pattern.
5. **Move the image** into `../images/` and empty this inbox.

You can also just paste/attach images in chat and say "add these to the style-board" — same process.
